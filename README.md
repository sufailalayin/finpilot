# FinPilot

**Personal Finance AI by Hastron Ventures**

FinPilot is a privacy-first personal finance platform with an Android app, AI-powered financial insights, a 7-day Pro trial, paid subscriptions, and a web-based administration console.

## Applications

- `mobile/` — Flutter Android application
- `backend/` — FastAPI API and finance/AI services
- `admin/` — Next.js administration dashboard
- `infra/` — deployment and infrastructure configuration
- `docs/` — product, architecture and operational documentation

## Initial product scope

1. Secure user registration and authentication
2. Accounts, income, expenses and categories
3. Budgets and savings goals
4. Dashboard and financial reports
5. AI personal finance assistant
6. 7-day Pro trial
7. Google Play subscription entitlement support
8. Admin user/subscription/AI-usage analytics
9. Audit logging and privacy controls

## Development

The repository is being built as a monorepo so the Android app, API and admin console evolve together with shared contracts.
